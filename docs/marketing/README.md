## Зафиксированное решение

Рабочее зонтичное название — **«СварДок»**. Текущий MVP — **«СварДок
Заявка»**.

Название предварительное: до покупки домена, разработки фирменного стиля и
публичного запуска обязательны проверка товарных знаков, доменов и совпадений
в профильных классах. Экспресс-поиск не заменяет юридическую проверку.
