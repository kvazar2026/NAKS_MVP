Страница партнёра (пример)

Это тестовая страница встраивания из репозитория, а не реальный сайт партнёра. Виджет ниже загружен через <iframe> и сам сообщает свою высоту через postMessage.

Открыть с разными параметрами: светлая тема тёмная тема неизвестные значения

Как встроить у себя

<iframe
  src="https://ВАШ-ХОСТ/?theme=light&partner=demo"
  title="Виджет преквалификации НАКС"
  width="100%"
  height="400"
  style="border: 0"></iframe>

<script>
  // Origin виджета. Проверка обязательна: без неё любое встроенное
  // содержимое сможет менять высоту вашего iframe.
  var WIDGET_ORIGIN = 'https://ВАШ-ХОСТ'

  window.addEventListener('message', function (event) {
    if (event.origin !== WIDGET_ORIGIN) return
    if (!event.data || event.data.type !== 'naks-widget:resize') return
    document.getElementById('naks-widget').height = event.data.height
  })
</script>

Чтобы виджет отправлял сообщения на ваш домен, его нужно собрать с переменной VITE_ALLOWED_PARENT_ORIGINS, содержащей origin вашей страницы (см. .env.example). Без этого виджет считает хост неизвестным и не отправляет ничего — он никогда не рассылает сообщения на *.
