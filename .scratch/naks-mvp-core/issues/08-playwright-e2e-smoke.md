# 08 — Playwright smoke-тест iframe-сценария

**What to build:** Автоматический тест поднимает весь стек через Docker
Compose, открывает тестовую страницу встраивания из тикета 05, проводит
виджет внутри настоящего iframe через минимально валидную отправку по
направлению «оборудование» и подтверждает, что пользователь реально получает
настоящий, открываемый скачанный `.docx`, без критических ошибок в консоли —
единственная автоматическая проверка, что iframe + backend + настоящий proxy
работают вместе, а не только по отдельности.

**Blocked by:** 05, 07.

**Status:** ready-for-agent

- [ ] Playwright-тест поднимает (или подключается к уже запущенному)
      Docker Compose стеку, открывает тестовую страницу встраивания из
      тикета 05.
- [ ] Тест дожидается загрузки виджета внутри iframe, заполняет минимально
      валидный опросник по направлению «оборудование», отправляет.
- [ ] Тест подтверждает, что появился экран результата и что скачанный файл
      — настоящий, открываемый `.docx` (файл реально открывается и
      проверяется, а не просто «есть ссылка на скачивание»).
- [ ] Тест подтверждает отсутствие критических/error-level сообщений в
      консоли браузера в течение сценария.
- [ ] Тест не пытается покрыть варианты валидации формы (это задача
      Vitest-тестов из тикета 02/03) — только критический сквозной путь
      встраивания.
- [ ] Задокументирована команда локального запуска этого теста (против
      compose-стека).
