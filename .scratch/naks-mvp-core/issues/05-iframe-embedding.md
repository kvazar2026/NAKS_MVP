# 05 — Встраивание через iframe

**What to build:** Страница виджета из тикета 02 встраивается через
`<iframe>` на отдельной тестовой HTML-странице из репозитория, автоматически
подстраивает высоту через `postMessage` на настроенный целевой `origin`,
принимает тему и идентификатор партнёра через безопасные параметры из
заранее определённого перечня (неизвестный partner-id — откат на демо-
конфигурацию с уведомлением, не ошибка), и отклоняет `postMessage` от
непредусмотренных `origin`.

**Blocked by:** 02.

**Status:** ready-for-agent

- [ ] Страница виджета читает `theme` и `partner` из query-параметров;
      `theme` принимает только значения из заранее определённого перечня
      (никакие произвольные CSS/URL/HTML через параметры никогда не
      рендерятся); неизвестный `partner` тихо откатывается на конфигурацию
      `demo` с уведомлением на странице.
- [ ] Виджет отправляет `window.parent` сообщения об изменении размера на
      настроенный разрешённый целевой `origin` (не `*` в документированном
      сценарии реального встраивания); входящие `postMessage`, если виджет их
      слушает, проверяют `event.origin` по allowlist перед обработкой.
- [ ] В репозитории есть тестовая HTML-страница, встраивающая виджет через
      `<iframe>`, и готовый HTML-пример встраивания в README/документации.
- [ ] Бизнес-логика формы не завязана напрямую на факт нахождения внутри
      iframe — контейнер встраивания вынесен в отдельный модуль (проверяется
      по структуре кода, не только по поведению).
- [ ] Тесты: значение `theme` вне перечня игнорируется/откатывается на
      значение по умолчанию; неизвестный `partner` откатывается на демо с
      видимым уведомлением; сообщение о ресайзе отправляется при изменении
      содержимого.
