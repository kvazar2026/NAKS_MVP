# 03 — Черновые предупреждения по типовым ошибкам

**What to build:** При отправке комбинации ответов по направлению
«оборудование», похожей на типовую ошибку из `naks-checklist-monetization.md`
(например, смешение аттестации технологии и оборудования, отсутствие
привязки к ОПО), пользователь теперь видит неблокирующее предупреждение с
объяснением, источником и статусом проверки — документ всё равно
генерируется.

**Blocked by:** 02.

**Status:** ready-for-agent

- [ ] Определён формат конфигурации справочника правил, загружается при
      старте; каждая запись обязана нести: код, направление, условие,
      уровень (`error`/`warning`), объяснение, источник, статус проверки,
      дата последней проверки. Запись без обязательных полей — ошибка
      загрузки конфигурации (fail-fast, не молчаливый пропуск).
- [ ] Минимум типовые ошибки по «оборудованию» из
      `naks-checklist-monetization.md` (смешение технологии/оборудования,
      отсутствие расходников/точных данных, необоснованное расширение
      области — в адаптации под административные поля этого MVP) закодированы
      как правила уровня `warning` с `source: naks-checklist-monetization.md`
      и `review_status: unverified`.
- [ ] `/api/v1/survey/validate` прогоняет правила уровня `warning` по
      нормализованным (после LLM) данным и включает сработавшие в ответ, не
      блокируя успех.
- [ ] Возвращаемые предупреждения несут объяснение/источник/статус проверки.
- [ ] Frontend показывает предупреждения отдельно от блокирующих ошибок, с
      формулировкой «предварительная автоматическая проверка, требует
      подтверждения специалистом или АЦ», не блокируя отправку/скачивание.
- [ ] pytest: вход, попадающий под известное правило-предупреждение,
      возвращает его и всё равно успешно генерирует документ; вход, не
      попадающий ни под одно правило, возвращает пустой список предупреждений;
      некорректная запись в конфигурации правил приводит к явной ошибке
      старта.
- [ ] Vitest + RTL: блок предупреждений рендерится с объяснением и
      дисклеймером; не блокирует отправку/скачивание.
