# CLAUDE.md

Инструкции для Claude Code. Общие и обязательные правила находятся в `AGENTS.md` — прочитай его перед работой.

## Порядок работы

1. Кратко сформулируй план и одним сообщением задай необходимые вопросы.
2. Дождись явного разрешения на выполнение.
3. Изучи только относящиеся к задаче файлы; не загружай всю историю без необходимости.
4. Вноси минимальные согласованные изменения.
5. Запусти доступные проверки и кратко сообщи результат.

## Особенности Claude Code

- Используй `AGENTS.md` как основной источник проектных правил; этот файл не должен его дублировать.
- Перед предложением архитектуры учитывай, что `backend/` и `frontend/` пока являются пустым каркасом.
- Не считай `naks_parser.py` готовым парсером: URL, селекторы и схема данных требуют проверки на актуальном сайте НАКС.
- Не создавай коммиты, ветки, публикации или внешние интеграции без отдельного запроса.
- Ответы пользователю — только на русском; код и технические идентификаторы — на английском.

## Команды и проверки

В проекте пока нет файла зависимостей, сборки, линта или тестов — не придумывай их.

- Синтаксическая проверка после правок `naks_parser.py`: `python -m py_compile naks_parser.py`.
- Запуск прототипа (требует `requests`, `beautifulsoup4`, `pandas`, установленных вручную): `python naks_parser.py`.
- Когда в `backend/` или `frontend/` появится реальный стек, этот раздел нужно обновить командами сборки/линта/тестов.
